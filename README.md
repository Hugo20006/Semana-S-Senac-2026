# 🐍 Semana S — SENAC 2026

> **Guia visual de debug em Python** desenvolvido para o evento nacional **Semana S do SENAC**, realizado presencialmente nos dias **15 e 16 de maio de 2026** em todo o território brasileiro.

---

## 📌 Sobre o Projeto

Este repositório reúne os **5 exercícios práticos de debug** apresentados durante o evento, acompanhados de **guias visuais em PDF** com o passo a passo de identificação e correção de erros em Python.

O objetivo foi mostrar que debugar não é só corrigir o erro — é entender o **raciocínio por trás da solução**.

---

## 📂 Estrutura do Repositório

Cada problema possui dois arquivos:

| Arquivo | Descrição |
|---|---|
| `Problema N - Nivel.py` | Código Python com os erros propositais |
| `Problema N - Nivel.pdf` | Guia visual com o passo a passo da correção |

## ▶️ Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/Hugo20006/Semana-S-Senac-2026.git
```

2. Acesse a pasta:
```bash
cd Semana-S-Senac-2026
```

3. Execute qualquer arquivo Python:
```bash
python "Problema 1 - Facil.py"
```

> **Nota:** O Problema 5 requer que o Tkinter esteja disponível no seu ambiente Python. Em geral, já vem instalado com o Python padrão.

---

## 📖 Como Usar os Guias PDF

Cada `.pdf` acompanha o respectivo `.py` e mostra:

1. O **código com erro** destacado
2. A **explicação** do que está errado e por quê
3. O **código corrigido** com o resultado esperado

Ideal para quem está aprendendo a programar e quer desenvolver o pensamento de debug desde cedo.
